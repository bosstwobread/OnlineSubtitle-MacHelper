# OnlineSubtitle for MacHelper

Install this folder with **MacHelper → Extensions → Install Source…** using MacHelper 6.9.0 or later. Review the listed companion identities and shared AI access before enabling. Then use **Browser Companions → Set Up…** to prepare the companion and complete the browser’s installation approval.

Open **Extensions → OnlineSubtitle → Settings** to choose a target language and edit the three prompts. MacHelper saves each prompt to the corresponding file under `prompts/`. The default translation language is Simplified Chinese. Prompts receive the selected target language through the model’s JSON input. When bringing over a customized prompt from 0.3.0, adapt it to the new input object with `targetLanguage` and `cues` so it follows the language menu.

MacHelper runs this package in its bundled JavaScript worker. OnlineSubtitle owns its captions, word lookup, prompts, and result validation. The approved companion commands read the effective caption preferences, translate captions, or explain a word clicked in the original captions. When YouTube identifies the audio language, OnlineSubtitle requests that language’s caption track or transcript independently of the language selected under YouTube’s Subtitles/CC menu. In Chrome and Edge, Netflix uses the subtitles selected in its **Audio & Subtitles** menu. Lookup uses the source caption as context and returns the word’s meaning in the selected language. The settings reply contains the target language and a revision identifier. Translation and lookup use MacHelper’s saved **AI Connection**.

See the [browser companion documentation](https://github.com/bosstwobread/OnlineSubtitle-MacHelper/blob/1314f1aabd18b47d774cf85f4c1bcddf0858e263/BrowserCompanions/README.md) for developer packages, Safari signing, and legacy Chrome setup.
